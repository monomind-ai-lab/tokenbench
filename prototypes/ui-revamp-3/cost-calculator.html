How the estimate is bounded

Cache-read and cache-write shares are portions of adjusted input tokens. If their sum is above 100%, cache-write volume is reduced so the total cannot exceed all input tokens.

When a cache-write rate is unavailable in a model fixture, the derived estimate uses that model’s standard input rate and says so in the source table.
